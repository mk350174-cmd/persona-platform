PersonaNeedle Android Dependencies (integration note — not a full build.gradle)

Add to app/build.gradle.kts:

dependencies {
    // 1. llama.cpp Android JNI (GGUF inference)
    implementation("com.llama.llamacpp:llama-android:0.0.14")
    // 2. OkHttp (WebSocket for McpBridge)
    implementation("com.squareup.okhttp3:okhttp:4.12.0")
    // 3. Kotlin coroutines
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-android:1.7.3")
}

android {
    defaultConfig {
        minSdk = 26        // Android 8.0
        targetSdk = 34     // Android 14
        ndk { abiFilters += listOf("arm64-v8a", "x86_64") }   // arm64-v8a required; x86_64 = emulator
    }
}

Assets layout (one folder per persona, from needle/pipeline/bulk_bundler.py):
    src/main/assets/personas/{persona_id}/
    ├── model.gguf       (or {persona_id}.gguf)
    ├── klayer.json
    ├── manifest.json
    └── avatar.png       (visual, optional)

NDK 25+ required for the llama.cpp JNI build.
