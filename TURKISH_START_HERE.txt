================================================================================
WHAT HAPPENS AUTOMATICALLY
================================================================================

The async monitor (scripts/async_monitor_turkish.py) will:

1. Poll every 1 hour for Turkish .docx file
2. Detect file by these patterns:
   - *turkish*.docx
   - *HPEP*.docx
   - hpep100_tr.docx

3. When detected, automatically:
   ✅ Run Stage 1 (Parse)        — Extract 50 questions
   ✅ Run Stage 2 (Translate)    — Call Gemini API
   ✅ Run Stage 3 (Integrate)    — Update API + tests
   ✅ Log results                — Update status file

4. No manual intervention needed!
